# Ouryn Brand Assets

## Primary logo

Use `ouryn-lockup.svg` for the final V5 standard vertical logo lockup. It uses the smooth Open O mark without the inner highlight and the smaller, proportion-refined tagline.

## Supporting assets

- `ouryn-lockup-on-dark.svg`: the primary lockup on a dark rounded background, for light pages such as the repository README. The silver wordmark is not legible on white. `ouryn-lockup-on-dark.png` is the same image rendered at 960px wide with an opaque background, used in the README because some viewers rasterize SVGs at low resolution.
- `ouryn-symbol.svg`: final V5 symbol-only mark.
- `ouryn-wordmark.svg`: final V5 horizontal symbol and wordmark.
- `ouryn-lockup-motion-highlight.svg`: final V5 temporary highlighted lockup for motion moments such as launch, completion, or transitions. Do not use it as the default static logo.

The matching V5 source files use the `-v5.svg` suffix. Earlier and exploratory files remain available for design history and comparison.
