# 2026년 11월 UX 점검 — 사용자 유형별

여러 사용자 입장에서 주요 화면 흐름을 **코드로 따라가며** 본 점검입니다. 실제 사용자 테스트나 화면 캡처가 아니라서 레이아웃·시각적 문제는 다루지 못했고, 거래소 정책은 확인하지 못했습니다. 반영 브랜치는 `security/2026-10-review`이고, 이 작업도 컴파일러 없이 했으므로 Mac 빌드가 필요합니다.

## 확인 방법 (Mac)

- 카메라 권한을 끈 상태에서 QR 찍기 → 체험 버튼 없이 설정 열기·사진 불러오기만 나오는지
- 솔라나 USDC 금액 요청 QR을 Phantom으로 찍기 → 받는 주소·USDC·금액이 채워지는지, Ouryn으로 찍어도 같은지
- 받기 → '확인 중인 입금'(BTC 테스트넷4로 보내고 블록 전에 확인)
- 송금 확인 화면에서 1분 넘게 기다렸다가 보내기 → 견적을 새로 받아 보내지는지, 수수료가 오르면 새 견적이 보이는지
- Trust Wallet 방식 솔라나 잔액이 있는 12단어로 처음 설치 복구 → 알림이 오고, '다른 앱 지갑 가져오기'에 같은 12단어를 넣으면 Trust Wallet 방식 통장이 가져와지는지
- 모르는 주소에서 받은 소액 거래 상세 → '보내기' 버튼 없음·사기 주의 안내
